---

Install `@nexus-js/core` and the adapter that connects your JavaScript contexts.
Choose one of the following setups.

## Chrome Extensions

For communication between background, content scripts, and extension pages:

<InstallCommand packages="@nexus-js/core @nexus-js/chrome" />

Continue with the [quick start](/nexus/docs/getting-started/) to provide and call
your first service.

## Parent Pages And Iframes

For communication between a parent window and an embedded iframe:

<InstallCommand packages="@nexus-js/core @nexus-js/iframe" />

Configure the two contexts using the [iframe guide](/nexus/docs/iframe/).

## Local Node Processes

For communication between a local daemon and clients over Unix sockets:

<InstallCommand packages="@nexus-js/core @nexus-js/node-ipc" />

Configure the daemon and client using the
[Node IPC quick start](/nexus/docs/node-ipc/quick-start/).

## Other Transports

If your application supplies its own endpoint, install Core:

<InstallCommand packages="@nexus-js/core" />

See [platforms and custom endpoints](/nexus/docs/platforms/) for the transport
contract. Ordinary application code can use an existing adapter instead.

## Next Step

Once both contexts are configured, the Core workflow is the same:

```ts
const connection = await app.connect({ target });
const service = connection.get(ServiceToken);
const result = await service.method();
```

The [quick start](/nexus/docs/getting-started/) supplies the shared contract,
provider, and consumer for a complete example. Additional capabilities can be
added later; see the [package reference](/nexus/docs/reference/packages/).
