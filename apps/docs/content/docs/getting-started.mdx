Call a background service from a Chrome extension content script using a shared
TypeScript contract. This guide assumes an existing extension project with both
bundles registered in its manifest.

<Callout type="warn" title="Configure both sides">
  The background context and content script each need their own Nexus setup.
</Callout>

<Steps>
<Step>

## Install The Core Package

<InstallCommand packages="@nexus-js/core @nexus-js/chrome" />

For other package combinations, see [Packages](/nexus/docs/packages/). For

</Step>
<Step>

## Define A Shared Contract

Put the token in code that both the background and content-script bundles can
import. If the service type already exists, import it instead of redefining it.

```ts title="service-contract.ts"
export interface PingService {
  ping(input: string): Promise<string>;
}
```

```ts
import { Token } from "@nexus-js/core";
import type { PingService } from "./service-contract";

export const PingToken = new Token<PingService>("example:ping-service");
```

`Token<T>` connects the compile-time service shape to its runtime identity.

</Step>
<Step>

## Publish A Provider

Use the Chrome helper in the background bundle and expose the provider there:

```ts
import { usingBackgroundScript } from "@nexus-js/chrome";
import { PingToken } from "./shared";
import type { PingService } from "./service-contract";

const backgroundNexus = usingBackgroundScript();

@backgroundNexus.Expose(PingToken)
class PingServiceImpl implements PingService {
  async ping(input: string): Promise<string> {
    return `pong:${input}`;
  }
}
```

An already-created object can be registered instead:

```ts
backgroundNexus.provide(PingToken, {
  async ping(input) {
    return `pong:${input}`;
  },
});
```

Use the instance-bound decorator for classes and `provide(...)` for object
providers or live registration.

</Step>
<Step>

## Connect And Get A Service

Configure the content script, connect to the background, then get its provider:

```ts
import { chromeTarget, usingContentScript } from "@nexus-js/chrome";
import { PingToken } from "./shared";

const contentNexus = usingContentScript();
const connection = await contentNexus.connect({
  target: chromeTarget.background(),
});
const remote = connection.get(PingToken);

console.log(await remote.ping("hello")); // "pong:hello"
```

`connect(...)` returns a ready shared session. `connection.get(...)` checks the
current provider catalog synchronously and returns a lightweight proxy. Use the
safe forms when either boundary is expected to fail:

```ts
const connected = await contentNexus.safeConnect({
  target: chromeTarget.background(),
});

if (connected.isErr()) {
  console.error(connected.error.code, connected.error.message);
} else {
  const service = connected.value.safeGet(PingToken);
  if (service.isErr()) console.error(service.error.code);
  else console.log(await service.value.ping("hello"));
}
```

`safeGet` covers service acquisition, not calls. A proxy call is lazy: it sends
only when consumed with `await`, `then`, or a native Promise helper. Use
`Nexus.safeCall(proxy.method())` when a single RPC failure should be a Result.

<Callout type="warn" title="Proxies are session-bound">

- A proxy is bound to the connection that supplied it.
- Disconnect, reload, daemon restart, or session replacement invalidates it.
- Connect again and get a new proxy; it does not silently retarget or reconnect.

</Callout>

</Step>
</Steps>

## Know What "Working" Means

The content script should print `pong:hello`. If it fails, check that both helpers ran in the intended bundles, the provider
uses the same `Token`, and the target resolves to the expected destination.

## Migrating Existing Code

Core 2.0 alpha removes the one-step acquisition and provider-wait APIs. Replace
`create`/`safeCreate` with `connect`/`safeConnect`, then use `get`/`safeGet` on
the returned connection. Replace both old multicast families with
`connectMulticast(...).get(Token)`. See the [Core 2.0 alpha migration](/nexus/docs/migrations/2.0-alpha/)
for the full contract and the default-target removal.
