---
title: 运行时兼容性
description: Node IPC 适配器对运行时和平台的要求。
---

`@nexus-js/node-ipc` 通过 `node:net` 使用文件系统 Unix 套接字，并通过 `node:path`、`node:os` 和 `node:fs/promises` 管理地址和套接字文件。

| 环境             | 使用边界                                                                   |
| ---------------- | -------------------------------------------------------------------------- |
| Linux 上的 Node  | 主要运行时，也是文档与测试覆盖的环境。                                     |
| 其他类 Unix 系统 | 需要支持文件系统 Unix 套接字；请在目标平台验证守护进程与客户端的完整流程。 |
| Bun              | 仓库 CI 尚未验证其兼容性。                                                 |
| 浏览器           | 不支持，请使用浏览器适配器。                                               |
| Electron         | 可用于本地 Unix 套接字通信，不替代 Electron 主进程与渲染进程之间的 IPC。   |

此传输不使用 `child_process.fork()` 或 `Bun.spawn({ ipc })` 的 IPC 通道，也不传递套接字句柄，因此这两种机制的序列化差异不适用于本适配器。

公共地址类型保留了抽象套接字形式，但目前文档和测试使用文件系统套接字。参阅[寻址](/nexus/docs/node-ipc/addressing/)。
